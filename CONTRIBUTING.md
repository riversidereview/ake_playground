# Contributing

Contributions are welcome through pull requests.

- Keep production credentials, real user data, extracted game assets, and raw
  captures out of commits.
- Use synthetic fixtures with `example.com`, RFC 5737 test IP addresses, and
  invented identifiers.
- Add or update tests for parser, API, and UI behavior.
- Do not weaken server-side validation in order to make a client upload pass.
- Run the checks documented in the root README before opening a pull request.

By submitting a contribution, you agree that it may be distributed under the
repository's MIT License.
