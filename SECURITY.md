# Security policy

Please do not open a public issue for a vulnerability that could expose user
data, bypass upload validation, or compromise a deployment.

Use GitHub's private vulnerability reporting for this repository. Include the
affected component, impact, reproduction steps, and a minimal proof of concept.
Do not attach real user logs, credentials, database exports, or packet captures.

The maintainers do not accept leaked keys or third-party confidential material.
If a report depends on such material, describe the condition without uploading
the material itself.
